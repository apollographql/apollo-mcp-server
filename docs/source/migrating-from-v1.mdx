## Before you begin

- Review the [CHANGELOG](https://github.com/apollographql/apollo-mcp-server/blob/main/CHANGELOG.md) for every release between your current v1.x version and v2.0.0.
- Back up your current `config.yaml` and any scripts that set `APOLLO_MCP_*` environment variables.
- If you run Apollo MCP Server via the [Apollo GraphOS Operator](./deploy#deploy-on-kubernetes-with-the-apollo-graphos-operator-recommended-for-kubernetes) or a container image, confirm the v2 image tag before changing your deployment manifests.
